# Telegram-бот для мастера маникюра

Бот для записи клиентов с расписанием, админ-панелью, проверкой подписки и напоминаниями.

## Структура проекта

```
bot/
├── bot.py                 # Точка входа, запуск бота
├── config.py              # Конфигурация (токен, ID админа, канал и т.д.)
├── requirements.txt       # Зависимости Python
├── manicure_bot.db        # SQLite база (создаётся при первом запуске)
├── README.md              # Инструкция
│
├── database/              # Работа с БД
│   ├── __init__.py
│   ├── db.py              # Операции с SQLite
│   └── models.py          # Схема таблиц
│
├── handlers/              # Обработчики сообщений
│   ├── __init__.py        # Регистрация роутеров
│   ├── states.py          # FSM-состояния
│   ├── user.py            # Запись, отмена
│   ├── admin.py           # Админ-панель
│   └── common.py          # Прайсы, портфолио
│
├── keyboards/             # Клавиатуры
│   ├── __init__.py
│   └── inline.py          # Inline-кнопки
│
└── utils/                 # Утилиты
    ├── __init__.py
    ├── scheduler.py       # APScheduler, напоминания
    └── channel_check.py   # Проверка подписки на канал
```

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Настройка

1. **Получите токен бота** у [@BotFather](https://t.me/BotFather).

2. **Создайте канал** для публикации расписания и проверки подписки.
   - Добавьте бота в канал как администратора.
   - Узнайте ID канала (например, через @userinfobot или @getidsbot).

3. **Отредактируйте `config.py`** или задайте переменные окружения:

| Переменная     | Описание                          |
|----------------|-----------------------------------|
| BOT_TOKEN      | Токен бота от BotFather           |
| ADMIN_ID       | Ваш Telegram ID (число)           |
| CHANNEL_ID     | ID канала (например, -1001234567890) |
| CHANNEL_LINK   | Ссылка на канал (https://t.me/...) |
| CHANNEL_USERNAME | @username канала (без @)        |

4. **Пример `.env`** (создайте файл при необходимости):

```
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
ADMIN_ID=123456789
CHANNEL_ID=-1001234567890
CHANNEL_LINK=https://t.me/your_channel
CHANNEL_USERNAME=your_channel
```

## Запуск

```bash
python bot.py
```

Для запуска с переменными из `.env` можно использовать `python-dotenv`:

```bash
pip install python-dotenv
```

И добавить в начало `bot.py`:

```python
from dotenv import load_dotenv
load_dotenv()
```

## Первый запуск

1. После первого запуска бот создаст БД `manicure_bot.db`.
2. Войдите в бот как администратор и выполните команду **`/admin`**.
3. Добавьте рабочие дни (кнопка «Добавить рабочий день») — дата в формате `ГГГГ-ММ-ДД`.
4. При добавлении дня автоматически создаются слоты с 09:00 до 20:00 по 60 минут.
5. Дополнительные слоты можно добавить через «Добавить слоты».

## Функционал

- **Записаться** — выбор даты и времени, проверка подписки, ввод имени и телефона.
- **Прайсы** — прайс-лист (Френч, Квадрат).
- **Портфолио** — ссылка на Pinterest.
- **Отменить запись** — отмена своей записи.
- **Админ** (`/admin`) — управление расписанием, добавление/удаление слотов, закрытие дней, отмена записей клиентов.

## Напоминания

За 24 часа до записи бот отправляет напоминание. Задачи восстанавливаются при перезапуске бота.
